# Docs accessibility

> **Goal**: the docs site is usable by everyone, including people
> using screen readers, keyboard navigation, and high-contrast modes.

This page covers, in order: **what**, **when**, **quickstart**, **config**,
**test**, **prod**, **escape**, **troubleshoot** (DOC-018).

---

## What

OgonGo's docs site (DOC-035) follows WCAG 2.1 AA:

- **Semantic HTML** — every page has one `<h1>`, headers are nested
  in order, lists are `<ul>`/`<ol>`, tables have `<thead>`.
- **Alt text** on every image; decorative images use `alt=""`.
- **Keyboard navigation** — every interactive element is reachable
  via Tab; focus is visible.
- **Color contrast** — text ≥ 4.5:1, large text ≥ 3:1.
- **No motion** — `prefers-reduced-motion` is respected; no
  auto-playing animations.
- **Search** (DOC-015) is keyboard-only (`/` to focus, `Esc` to
  clear); results are announced via `aria-live`.
- **Code blocks** — line numbers are `aria-hidden`; the code itself
  is a `<pre><code>` with `language-*` for syntax highlighting.

## When

- Before adding a new docs page.
- Before adding an image, diagram, or interactive widget.
- When the a11y lint (DX-032) fails.

## Quickstart

The site is generated by `ogon docs build`. The a11y checks are part
of the docs lint:

```bash
ogon docs lint
# -> check: a11y-headings   ok  (every page has one h1, nested in order)
# -> check: a11y-alt        ok  (every img has alt)
# -> check: a11y-contrast   ok  (text >= 4.5:1)
# -> 3 ok, 0 fail
```

## Config

`docs/ogon-docs.yaml` (generated by `ogon new --template standard`):

```yaml
site:
  title: OgonGo Docs
  theme: default            # default | high-contrast | serif
  search: pagefind
  a11y:
    level: WCAG_2_1_AA
    check_contrast: true
    check_motion: true
```

## Test

DX-032 (docs lint) includes the a11y checks. The site is also tested
with `test.PlaywrightA11y` (axe-core) in CI; AT-014 ("Form works with
JS disabled") is part of the suite.

## Prod

The site is published with `ogon docs deploy`. The a11y checks run
before deploy; a failure blocks the deploy.

## Escape

- **Custom theme**: set `site.theme` in `docs/ogon-docs.yaml`; the
  high-contrast theme is available out of the box.
- **Skip a11y**: not allowed; the lint is non-negotiable.

## Troubleshoot

| Symptom                                | Fix                                                            |
|----------------------------------------|----------------------------------------------------------------|
| `a11y-contrast` fails                  | Bump the text color; the linter shows the ratio.               |
| `a11y-alt` fails                       | Add `alt` to the image, or `alt=""` if decorative.             |
| Screen reader skips a heading          | Headers are out of order; restructure with one h1, then h2s.   |
| Search results are not announced       | The `aria-live` region is missing; rebuild with `ogon docs build`. |

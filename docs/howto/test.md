# How-to — Test an OgonGo service

> **Goal**: write the four kinds of tests OgonGo projects need (unit,
> HTTP integration, DB-backed, end-to-end), wire them into CI, and use
> the framework's fixtures so you write tests, not plumbing.

This page covers, in order: **what**, **when**, **quickstart**, **config**,
**test**, **prod**, **escape**, **troubleshoot** (DOC-018).

---

## What

The `test` package ships the fixtures you would otherwise write by hand
in every Go web project:

| Fixture                          | What it gives you                                          |
|----------------------------------|------------------------------------------------------------|
| `test.NewApp(t, handler)`        | In-process server + `httptest.Recorder`, no port.          |
| `test.NewDBTx(t)`                | Transaction-rollback DB; fast, parallel-safe.              |
| `test.NewTruncationDB(t)`        | Opt-in for DDL that cannot live in a tx.                   |
| `test.QueryCounter`              | Wraps the DB and asserts N+1 absence.                      |
| `test.Recorder()`                | `GET/POST/PUT/DELETE` with `AssertStatus`, `AssertJSON`.   |
| `test.WSClient`, `test.SSEClient`| Realtime clients with auto-reconnect.                      |
| `test.JobRunner`                 | Run jobs inline in tests; assert retry / DLQ.              |
| `test.NewAuthzMatrix`            | Generate a role x route matrix from your `routes/`.        |
| `test.RedactionCorpus()`         | Assert your model has no PII in span attrs.                |
| `test.MemoryLeakSoak`            | Run a handler 10k times; assert RSS does not grow.         |
| `test.FakeClock`                 | Time-dependent testing without `time.Sleep`.               |
| `test.PlaywrightConfig`          | Generate `playwright.config.ts` for e2e tests.             |

`ogon test` is a thin wrapper over `go test` that adds fixtures and
optional JUnit XML output.

## When

Use the `test` package whenever you write a test. The fixtures are
parallel-safe by default and integrate with the framework's redaction,
auth, and DB subsystems.

## Quickstart

### Unit + HTTP

```go
// SPDX-License-Identifier: MIT
// Copyright (c) 2026 OgonFrameworks. All rights reserved.
//
// Hello route tests.

package routes

import (
    "net/http"
    "testing"

    ogonhttp "github.com/OgonFrameworks/ogon.go/http"
    "github.com/OgonFrameworks/ogon.go/test"
)

func TestHello(t *testing.T) {
    app := test.NewApp(t, ogonhttp.Handler())
    defer app.Close()

    r := app.Recorder().Get("/hello")
    r.AssertStatus(t, http.StatusOK)
    r.AssertJSON(t, `{"hello":"world"}`)
}
```

### DB-backed

```go
func TestUserCRUD(t *testing.T) {
    app := test.NewApp(t, ogonhttp.Handler())
    defer app.Close()

    db := app.DB()                  // transaction-rollback DB
    defer db.Rollback()

    r := app.Recorder().Post("/users", test.JSON(`{"email":"a@b.c","name":"A"}`))
    r.AssertStatus(t, 201)
}
```

### Realtime

```go
func TestChatRoom(t *testing.T) {
    app := test.NewApp(t, ogonhttp.Handler())
    defer app.Close()

    ws := app.WSClient("/room/1")
    defer ws.Close()

    ws.WriteJSON(map[string]string{"msg": "hi"})
    msg, err := ws.ReadJSON(2 * time.Second)
    test.AssertNoError(t, err)
    test.AssertEqual(t, "hi", msg["msg"])
}
```

### Authz matrix

```go
//go:generate ogon gen authz-matrix

func TestAuthzMatrix(t *testing.T) {
    test.NewAuthzMatrix(t, "routes/").Run(
        // generated table of (user, route, expected status)
    )
}
```

### Memory-leak soak

```go
func TestNoLeak(t *testing.T) {
    app := test.NewApp(t, ogonhttp.Handler())
    defer app.Close()

    test.MemoryLeakSoak(t, 10_000, func() {
        app.Recorder().Get("/heavy")
    })
}
```

## Config

`ogon.yaml` test section:

```yaml
test:
  parallel: true
  race: true
  timeout: 5m
  junit: ./build/junit.xml
  fixtures:
    db: tx-rollback          # tx-rollback | truncation | testcontainers
    redis: inproc            # inproc | testcontainers
```

CI uses `testcontainers` for real Postgres/Redis; local dev uses
`tx-rollback` and `inproc` for speed.

## Test

```bash
ogon test                            # go test + fixtures
ogon test --race --json              # race + JSON output for CI
ogon test -run TestUser              # filter
ogon test --junit ./build/junit.xml  # emit junit XML
ogon test --cover                    # coverage
ogon test --cover-package=./...      # coverage across packages
```

## Prod

CI is generated by `ogon infra gen ci`. The pipeline runs:

```bash
ogon fmt
ogon lint
ogon check
ogon test --race --junit ./build/junit.xml
ogon benchmark --suite dx
ogon benchmark --suite perf
```

A failing step fails the build; the JUnit XML is published to the CI
UI for test triage.

## Escape

- **Plain `go test`**: every fixture works without `ogon test`; it is
  a thin wrapper.
- **testcontainers**: `test.NewPostgresContainer(t)` and
  `test.NewRedisContainer(t)` for real services in CI.
- **Custom fixtures**: implement the `test.App` interface and pass it
  to `test.NewAppWithCustomFixture`.

## Troubleshoot

| Symptom                                                | Fix                                                              |
|--------------------------------------------------------|------------------------------------------------------------------|
| `panic: database closed`                               | You forgot `defer app.Close()`.                                  |
| Tests fail in CI but pass locally                      | Local env drifted; `ogon doctor` checks the toolchain.            |
| `MemoryLeakSoak` reports RSS growth                    | Use `go test -run TestNoLeak -tags=leak` and inspect with pprof. |
| `testcontainers` fails to start                        | Docker daemon not running; CI uses `services: docker:dind`.      |
| `TestAuthzMatrix` is missing a route                   | The generator is stale; re-run `ogon gen authz-matrix`.          |

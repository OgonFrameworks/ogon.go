# API reference

> **Goal**: index the OgonGo public API surface, with links to the
> godoc and the per-package purpose.

This page covers, in order: **what**, **when**, **quickstart**, **config**,
**test**, **prod**, **escape**, **troubleshoot** (DOC-018).

---

## What

OgonGo's API reference is generated by `go doc` and hosted at
<https://pkg.go.dev/github.com/OgonFrameworks/ogon.go>. This page is
the docs-side index — the per-package purpose, the entry types, and a
link to the godoc.

To regenerate this page locally:

```bash
go doc -all ./... > docs/reference/godoc.txt
```

(DOC-016: godoc + extended API reference.)

## When

- You want the canonical signature of a function.
- You want to discover what's in a package without reading the source.
- You are writing an agent and need the type surface.

## Quickstart

```bash
# browse online
open https://pkg.go.dev/github.com/OgonFrameworks/ogon.go

# local godoc
go doc ./http.Ctx
go doc ./record.Model

# full dump
go doc -all ./... > docs/reference/godoc.txt
```

## Config

No config — this is a reference page.

## Test

`go doc -all ./... > docs/reference/godoc.txt` runs in CI as a drift
check (DOC-016). If the dump changes, the PR must update this page.

## Prod

The reference is generated per release and published to
pkg.go.dev.

## Escape

- `go doc` is always available; you do not need the docs site.
- The `llms.txt` file at the repo root is the machine-readable mirror.

## Troubleshoot

| Symptom                                | Fix                                                            |
|----------------------------------------|----------------------------------------------------------------|
| pkg.go.dev shows an old version         | Run `go proxy` or wait for the indexer.                        |
| `go doc` shows a different signature    | Your local checkout is dirty; `git status`.                    |
| A package is missing from this page     | File a docs bug; the index is hand-curated.                    |

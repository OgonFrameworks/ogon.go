# CRUD example

A blog with one resource (`Post`) generated by `ogon gen resource`.

## Run

```bash
ogon migrate run
ogon dev

curl :3000/posts -d '{"title":"hi","body":"world","author_id":1}'
curl :3000/posts
```

## Files

```
crud/
├── ogon.yaml
├── main.go
├── models/Post.go         # developer-edited
├── routes/Post.go         # generated (ogon:owned)
├── handlers/Post.go       # developer-edited
├── migrations/0001_post.up.sql
├── migrations/0001_post.down.sql
└── Post_test.go           # generated
```

## Test

```bash
ogon test --race
```

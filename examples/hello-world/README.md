# Hello-world example

The smallest OgonGo project: one route, dev supervisor, healthz.

## Run

```bash
ogon dev
# -> listening on http://localhost:3000

curl :3000/hello
# {"hello":"world"}

curl :3000/healthz
# {"status":"ok","version":"1.0.0"}
```

## Files

```
hello-world/
├── go.mod
├── ogon.yaml
├── main.go
├── routes/
│   ├── health.go          # generated by `ogon new`
│   └── hello.go           # the one developer-written file
└── README.md
```

## Test

```bash
ogon test
```

The test uses `test.NewApp` (in-process; no port).
